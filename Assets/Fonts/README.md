# Bundled typefaces

Inter, Roboto, Manrope, Outfit, Plus Jakarta Sans, and DM Sans are supplied under the SIL Open Font License. Each family directory includes its upstream OFL.txt with copyright notices. These licenses are also copied to the published output.

Sources: the corresponding family directories in the official Google Fonts repository, https://github.com/google/fonts/tree/main/ofl . Regular, Medium, SemiBold, and Bold static instances were generated from the upstream variable fonts using fontTools, with internal family/style names normalized for reliable Avalonia lookup. No system-wide installation is performed.

SF Pro and SF Pro Display are not bundled. The app uses them only if a copy is already installed on the user's computer.
